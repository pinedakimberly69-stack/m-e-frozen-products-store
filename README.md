# M&E Frozen Products Store

A simple and responsive web-based ordering platform developed for M&E Frozen Products Store. The website allows customers to browse available frozen products, manage their shopping cart, and proceed through a basic checkout and order confirmation process.

## Project Overview

The M&E Frozen Products Store website was developed to provide customers with a convenient way to view available frozen products and prepare orders online.

The system features a product catalog, shopping cart functionality, quantity restrictions, checkout interface, and order confirmation page.

## Key Features

### Product Catalog
- Displays available frozen products.
- Shows product names, categories, and prices.
- Provides individual quantity limits per product.

### Shopping Cart
- Add products to the shopping cart.
- Increase or decrease product quantities.
- Remove products from the cart.
- Automatically calculate order subtotals and totals.
- Save cart information using browser LocalStorage.

### Checkout System
- Provides a checkout interface.
- Displays order information and totals.
- Supports an order confirmation page.

### Ordering Schedule
- Orders are accepted Monday to Saturday.
- Operating hours: 9:00 AM – 5:00 PM.
- Customers can browse products and add items to their cart outside ordering hours.
